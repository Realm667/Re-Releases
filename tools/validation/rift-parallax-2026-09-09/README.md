# TNT04CN elliptical orbits and parallax validation

UZDoom 5.0.1 passes 42 lifecycle assertions across OpenGL and Vulkan: save/load, sky selection, original Source/sector count/secondary viewpoint, and transitions through TNT04C/B/A and back. Twelve views cover both portal rooms and different directions. The approved cloud opening and geometric beam endpoint stay clear.

`test_rift_orbits.py` verifies all seven closed elliptical paths and 238 world-space projection cases across complete revolutions and translated cameras. Periods are 130-240 seconds with different directions, phases and small radii.

`test_rift_parallax.py` measures actual GPU parallax with sky time frozen at 40 seconds. It reuses the unchanged production layer projection calls to output the selected near layer's alpha in blue and the selected far layer's alpha in green. This excludes overlapping layers and the independently animated beam from the measurement. Cameras stay inside the stacked room, aim at each test group's centre and translate 512 units sideways without turning. A fully visible connected contour is tracked in each layer; a 5% area bound allows small rasterization changes while rejecting substantial occlusion. The near contour moves 10.46-10.67 pixels and the far contour 2.06-2.07 pixels (about five times less). The same near view is repeated in lower-room coordinates to check portal normalization; its centroid is identical, with only 1-2 differing boundary pixels in the full mask. JSON files contain results for both renderers. The coloured images are diagnostic captures only, not production artwork.

All twelve static cubemap edges match exactly, the nadir is black, and all eighteen TNT04A/B/CN material faces retain the same comet source. The map hash is unchanged. The complete PK3 compiles fourteen ACS modules and matches eighteen relevant runtime resources byte-for-byte; a packaged Vulkan smoke run passes six additional assertions. The isolated commit tree is separately compile-checked. Concurrent local project work may be present in the complete working-copy PK3; only this task's files enter the commit.
