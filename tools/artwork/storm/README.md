# TNT01 storm artwork

The user approved `approved-mockup.png`, then requested implementation with
animated clouds. Mockup and production artwork were created with the built-in
ImageGen tool on 2026-09-08. `prompts.json` records the production prompts;
`mockup-prompt.json` records the original concept edit.

Source artwork, retained at original 1774 x 887 dimensions:

- `tutnt/graphics/storm/clouds.png`: isolated cloud panorama.
- `tutnt/graphics/storm/mountains-key.png`: mountain panorama with a blue key.

The generator initially returned RGB with a painted checkerboard despite the
transparent-background request. That version was rejected. The final keyed
mountain image was generated by replacing the checkerboard with blue while
preserving the mountains and valley haze. The game material removes the key
at runtime. Neither selected source is a screenshot or a captured real sky.

Cube projection and compositing are reproducible through
`tools/build_storm_sky.py`. The mockup is a design reference, not a screenshot
of the completed implementation. Actual gameplay captures are in the storm
validation directory.
